# townu
Towny is an all-in-one college-town platform connecting students, parents, local businesses and service providers. Students can buy and sell items, find housing, earn money through side hustles, discover local deals and services, parents can find trusted help such as laundry, cleaning, tutoring, moving, storage and care packages. 
we'll launch in Tuscaloosa for UA, Stillman and Shelton, then expand the same platform to college towns nationwide.
